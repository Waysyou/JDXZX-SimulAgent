# 本地整理范围

本候选版保留当前第二版的核心 Python 模块、当前接入界面和后端 API。没有重训模型、改变识别提交阈值、重写翻译提示词或重做前端。

整理内容：

- 新增独立 `run_local.py`、PowerShell 和 CMD 入口，使用本项目的虚拟环境及明确配置的资源路径。
- 安装脚本不再依赖随包私有 CUDA wheel，提供 CPU/CUDA 12.8 官方安装渠道选择，检查版本和每一步退出码。
- 显式记录 FastAPI、Uvicorn、multipart 等直接依赖。
- 不复制旧 UI 样板、缓存、运行结果、官方数据、模型和旧运行包。
- 默认 ASR 纠错表仍为空。开发集特定纠错文件不提供，翻译词表改为空模板，因此公开候选版不代表原比赛输出复现。
- 将涉及开发集场景词汇的测试改成现场编写的中性短文本、临时纠错配置和测试内局部词表。
- 加入团队贡献、模型来源、许可状态与公开前检查文档。

准备阶段仅进行不加载模型的单元测试、语法/配置检查与 HTTP 冒烟测试。真实模型推理、独立电脑重新安装和公开许可确认均需另行验证，不能据这些轻量检查声称全部完成。
